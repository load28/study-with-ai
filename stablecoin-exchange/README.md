# 스테이블코인 거래소 개발자 학습 로드맵

## 학습 목표
**부의 원리(선점 + 희소성)**를 이해하고, 스테이블코인 거래소의 핵심 기술을 러스트 기반으로 직접 구현할 수 있는 풀스택 블록체인 엔지니어로 성장합니다. 록펠러의 석유 산업 독점부터 현대 디지털 달러 패권까지의 맥락을 이해하고, "거래소를 만드는 기술력"이라는 곡괭이 비즈니스를 구축합니다.

## 학습 철학
- **원리부터**: 왜 스테이블코인인가, 왜 러스트인가를 이해한 후 기술로
- **수직 통합**: 매칭 엔진(러스트) → API 서버(Spring) → 프론트엔드(React) → 블록체인 연동(ethers.js)
- **기존 스킬 활용**: React/Next.js, Node.js, Java/Spring 역량을 최대한 레버리지
- **점진적 심화**: 러스트 기초 → 블록체인 기초 → 거래소 핵심 → 스테이블코인 특화
- **실전 중심**: 모든 개념은 직접 구현하는 프로젝트와 함께

## 사용 언어 & 도구
- **Rust** — 매칭 엔진 핵심 (Tokio, WebSocket)
- **Java/Spring** — 거래 API 서버 (기존 스킬 활용)
- **React/Next.js** — 거래소 프론트엔드 (기존 스킬 활용)
- **Node.js + ethers.js** — 블록체인 연동 (기존 스킬 활용)
- **Solidity** — 스마트컨트랙트 읽기 수준
- **PostgreSQL** — 거래 내역 관리

## 학습 방법
- 각 주차는 독립적인 문서로 제공됩니다
- **배경 지식 → 핵심 개념 → 코드 구현 → 실전 프로젝트** 순서
- 각 문서는 `week-XXX.md` 형식으로 저장됩니다 (3자리)
- 모든 코드는 직접 실행 가능한 수준

### 🦀 Phase 1: 러스트 기초 완성 (3-14주차)
> 매칭 엔진의 기반이 되는 러스트 완전 정복

**3주차: 러스트 시작하기 — 설치와 첫 프로그램**
- rustup, cargo 설치 및 환경 설정
- Hello World부터 cargo 프로젝트 구조
- 변수, 상수, 데이터 타입
- 함수와 제어 흐름
- **실전**: 간단한 주문 입력 CLI 만들기

**4주차: 소유권(Ownership) — 러스트의 핵심**
- 소유권 규칙 3가지
- 이동(Move)과 복사(Copy)
- 참조(Reference)와 빌림(Borrowing)
- 가변 참조와 불변 참조
- **실전**: 주문 데이터를 안전하게 전달하는 함수 설계

**5주차: 라이프타임(Lifetime) — 참조의 유효 범위**
- 라이프타임 어노테이션
- 함수 시그니처의 라이프타임
- 구조체의 라이프타임
- 라이프타임 생략 규칙
- **실전**: 오더북 참조 구조 설계

**6주차: 구조체와 열거형**
- struct로 도메인 모델링
- enum과 패턴 매칭
- Option<T>과 Result<T, E>
- impl 블록과 메서드
- **실전**: Order, OrderBook, Trade 타입 정의

**7주차: 컬렉션과 에러 처리**
- Vec, HashMap, BTreeMap
- 에러 처리 패턴 (?, unwrap, expect)
- 커스텀 에러 타입
- thiserror/anyhow 크레이트
- **실전**: 주문 저장소와 에러 처리 구현

**8주차: 트레이트(Trait) — 다형성과 추상화**
- 트레이트 정의와 구현
- 트레이트 바운드와 제네릭
- 기본 구현과 연관 타입
- Display, Debug, Clone, PartialOrd 구현
- **실전**: 다양한 주문 타입을 추상화하는 트레이트 설계

**9주차: 제네릭과 고급 타입 시스템**
- 제네릭 함수, 구조체, 열거형
- where 절과 트레이트 바운드 조합
- 정적 디스패치 vs 동적 디스패치 (dyn Trait)
- PhantomData와 타입 상태 패턴
- **실전**: 제네릭 매칭 엔진 인터페이스

**10주차: 모듈 시스템과 크레이트**
- mod, pub, use 키워드
- 파일 구조와 모듈 트리
- 크레이트와 Cargo.toml
- 외부 크레이트 활용 (serde, chrono)
- **실전**: 거래소 프로젝트 모듈 구조 설계

**11주차: 비동기 프로그래밍 기초 — async/await**
- Future 트레이트 이해
- async/await 문법
- Tokio 런타임 기초
- 비동기 함수와 핀(Pin)
- **실전**: 비동기 주문 처리 파이프라인

**12주차: Tokio 심화 — 동시성 패턴**
- tokio::spawn과 태스크
- Channel (mpsc, oneshot, broadcast)
- Mutex, RwLock (tokio::sync)
- select!와 join!
- **실전**: 다중 클라이언트 주문 동시 처리

**13주차: 네트워킹 — TCP와 WebSocket**
- tokio::net::TcpListener/TcpStream
- 프로토콜 설계 기초

- 메시지 직렬화 (serde_json)
- **실전**: WebSocket으로 실시간 호가 데이터 송수신

**14주차: 러스트 종합 프로젝트 — 간단한 매칭 엔진 CLI**

- **실전**: 완전한 CLI 기반 오더 매칭 엔진

### 🏗️ Phase 3: 거래소 핵심 기술 (23-36주차)
> 러스트 매칭 엔진 + Spring API + React UI

**23주차: 오더북 설계 — 자료구조와 알고리즘**
- 오더북이란 무엇인가
- 가격 레벨과 주문 큐

- **실전**: 러스트로 기본 오더북 자료구조 구현

- 가격-시간 우선순위(Price-Time Priority)
- 지정가(Limit Order) 매칭 로직
- 부분 체결(Partial Fill) 처리
- 매칭 결과(Trade) 생성
- **실전**: 지정가 주문 매칭 엔진 구현

**25주차: 매칭 알고리즘 (2) — 시장가와 고급 주문**

- FOK (Fill or Kill)
- 주문 취소와 수정
- **실전**: 다양한 주문 타입 지원 매칭 엔진

**26주차: 매칭 엔진 성능 최적화**
- 벤치마킹 (criterion 크레이트)
- 메모리 할당 최적화

- 초당 처리량(TPS) 측정

**27주차: WebSocket 실시간 데이터 송출**
