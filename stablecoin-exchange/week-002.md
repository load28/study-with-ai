# 2주차: 스테이블코인과 달러 패권 — 시장 심화 분석

## 왜 이것을 배우는가?

1주차에서 록펠러의 부의 원리와 "선점 + 희소성"의 패턴을 배웠다. 이제 그 원리를 **현재 시장에 적용**할 차례다.

스테이블코인은 단순한 암호화폐가 아니다. 미국 정부가 **법률로 뒷받침하는 디지털 달러 인프라**다. 2025년 7월 18일 지니어스법(GENIUS Act)이 서명되면서, 스테이블코인은 "실험적 기술"에서 **"제도권 금융 인프라"**로 격상됐다.

이번 주차에서는 지니어스법의 세부 조항을 분석하고, 주요 스테이블코인을 비교하며, 거래소 기술의 구체적인 사업 모델을 살펴본다.

---

## 1. 지니어스법(GENIUS Act) 심화 분석

### 1.1 법안의 경과

```
지니어스법 타임라인:

2025.02.04  상원 법안 발의 (S.394)
     ↓
2025.06.17  상원 통과 (찬성 68 : 반대 30) — 초당적 지지
     ↓
2025.07.17  하원 통과 (찬성 308 : 반대 122) — 압도적 다수
     ↓
2025.07.18  트럼프 대통령 서명 → 법률 발효
     ↓
2025.09.19  연방관보(Federal Register)에 시행 규칙 공포
     ↓
2026.01     OCC(통화감독청) 구체적 시행 규칙 제안(NPRM) 발표
     ↓
2027.01.18  최종 시행일 (서명 후 18개월, 또는 규칙 확정 후 120일 중 빠른 날)
```

**초당적 지지(Bipartisan Support)**가 핵심이다. 미국 정치에서 상원 68:30, 하원 308:122는 드문 수준의 합의다. 이것은 스테이블코인이 정치적 논쟁을 넘어 **국가 전략**으로 인식되고 있음을 의미한다.

### 1.2 핵심 조항 상세 분석

#### 조항 1: 발행사 자격 제한

```
지니어스법이 허용하는 스테이블코인 발행사 유형:

유형 1: 은행 자회사 (Insured Depository Institution Subsidiary)
  └── JPMorgan, Bank of America 등이 자회사를 통해 발행
  └── 기존 은행 규제 체계 내에서 감독

유형 2: 비은행 연방 면허 기관 (OCC-supervised Nonbank)
  └── Circle(USDC 발행사) 같은 핀테크 기업
  └── OCC(통화감독청)의 직접 감독

유형 3: 주(州) 인가 기관 (State-chartered Entity)
  └── 주 금융 규제 당국이 인가
  └── 단, 연방 기준과 동등한 규제가 적용되어야 함

❌ 비금융 기업 발행 금지:
  └── 테크 기업(예: 메타, 아마존)은 원칙적으로 발행 불가
  └── 예외: SCRC(스테이블코인 인증 심의 위원회)의 만장일치 승인
       → SCRC 구성: 재무장관(의장) + 연준 의장 + FDIC 의장
```

> 💡 **핵심 통찰**: 비금융 기업의 발행을 금지한 것은 Big Tech가 자체 화폐를 만드는 것(메타의 Libra/Diem 사태)을 방지하기 위한 조치다. 금융 시스템의 안정성을 기술 기업에게 맡기지 않겠다는 의지다.

#### 조항 2: 1:1 준비금 요건

```
준비금 구성 요건:

허용되는 준비 자산:
  ✅ 미국 달러 현금
  ✅ 미국 재무부 단기 국채 (Treasury Bills)
  ✅ 연방준비은행 예치금
  ✅ 기타 고유동성 자산 (규제 당국이 승인한 경우)

허용되지 않는 준비 자산:
  ❌ 기업 채권
  ❌ 주식
  ❌ 다른 암호화폐
  ❌ 장기 국채 (금리 리스크)
  ❌ 부동산

의무 사항:
  → 발행된 스테이블코인 1달러당 준비금 1달러 이상 보유
  → 월간 준비금 증명(Proof of Reserves) 보고
  → 연간 외부 회계감사 필수
```

이 조항이 만든 **구조적 효과**가 있다:

```
스테이블코인 발행 → 준비금으로 미국 국채 매입
                    ↓
                 미국 국채 수요 증가
                    ↓
                 미국 정부 차입 비용 감소
                    ↓
                 미국 재정에 직접 도움

2025년 10월 기준:
  스테이블코인 발행사들의 미국 국채 보유량 ≈ $1,550억 (약 211조 원)
  → 전 세계 미국 국채 보유 기관 중 상위권
  → 한국($1,200억)보다 많음!
```

> 💡 **핵심 통찰**: 지니어스법은 스테이블코인을 "규제"하는 것처럼 보이지만, 실질적으로는 스테이블코인이 미국 국채의 새로운 수요처가 되도록 **설계**한 것이다. 미국 정부와 스테이블코인 발행사의 이해관계가 구조적으로 일치한다.

#### 조항 3: 증권/상품 분류 면제

```
기존 상황 (지니어스법 이전):
  "스테이블코인이 증권인가?" → SEC와 법적 분쟁 리스크
  "스테이블코인이 상품인가?" → CFTC 관할 불확실

지니어스법 이후:
  지니어스법 준수 스테이블코인은:
    ❌ 증권(Security)이 아니다 → SEC 관할 아님
    ❌ 상품(Commodity)이 아니다 → CFTC 관할 아님
    ❌ 은행 예금(Bank Deposit)이 아니다 → FDIC 보험 적용 안 됨
    ✅ 독립적인 "결제용 스테이블코인(Payment Stablecoin)" 범주

→ 규제 불확실성 해소 = 기업과 투자자의 진입 장벽 대폭 하락
```

#### 조항 4: 외국 발행사 규제

```
외국 발행사가 미국 시장에서 활동하려면:

필수 요건:
  1. OCC에 등록
  2. 미국 금융기관에 준비금 보관
  3. 본국 규제가 미국과 동등하다는 재무장관의 인정

효과:
  → 미국 밖에서 발행된 스테이블코인도 미국 규제 체계 하에 편입
  → 달러 연동 스테이블코인의 글로벌 표준 = 미국 기준
  → 사실상 디지털 달러의 "브레턴우즈 체제"
```

#### 조항 5: 소비자 보호

```
파산 시 준비금 처리:

발행사가 파산하면:
  1순위: 스테이블코인 보유자에게 준비금 반환
  2순위: 기타 채권자

  → 일반 채권자보다 스테이블코인 보유자가 우선
  → 은행 예금의 FDIC 보험과 유사한 보호 (하지만 FDIC 보험은 아님)
```

### 1.3 지니어스법이 만드는 시장 구조

```
지니어스법 이전의 스테이블코인 시장:

  불확실한 규제 ← 리스크 높음
       ↓
  기관 투자자 진입 꺼림
       ↓
  소수 선점자만 활동 (Tether, Circle)
       ↓
  시장 성장 제한적

지니어스법 이후의 스테이블코인 시장:

  명확한 규제 프레임워크 ← 리스크 감소
       ↓
  대형 은행, 핀테크 대거 진입
       ↓
  인프라 수요 폭증 (거래소, 결제, 컴플라이언스)
       ↓
  기술 인력 수요 >> 공급
       ↓
  기술력을 가진 개발자의 가치 극대화
```

```
기본 정보:
  발행사: Tether Limited (등기: 영국령 버진아일랜드)
  출시: 2014년 (원래 "Realcoin"이라는 이름)
  시가총액: ~$1,868억 (2025년 말)
  운영 블록체인: Ethereum, Tron, Solana, Avalanche 등 다수
  월 평균 거래량: ~$7,030억

강점:
  ✅ 최대 유동성 — 전 세계 거래소에서 기본 거래쌍
  ✅ 다중 체인 지원 — 어디서든 사용 가능
  ✅ 트레이더 선호 — 빠른 결제, 범용적 사용
  ✅ 시장 선점 효과 — 2014년부터 운영

약점/리스크:
  ❌ 준비금 투명성 논란 — 수차례 감사 미이행 이슈
  ❌ 규제 리스크 — 미국 외 법인, 과거 NYAG 합의
  ❌ 지니어스법 적합성 불확실 — 외국 발행사 요건 충족 필요
  ❌ 중앙화 우려 — Tether가 계정 동결 가능
```

## 3. 전통 금융 vs 스테이블코인 — 왜 대체되는가

### 3.1 국제 송금 비교

```
시나리오: 한국에서 미국으로 $10,000 송금

전통 은행 (SWIFT):
  ┌──────────────────────────────────────┐
  │ 한국 은행 → 중개 은행 → 미국 은행     │
  │ 소요 시간: 2~5 영업일                  │
  │ 수수료: $25~50 (송금) + 환전 스프레드   │
  │ 운영 시간: 평일 9~17시                 │
  │ 추적: 불투명 (어디에 멈춰있는지 모름)   │
  └──────────────────────────────────────┘

스테이블코인 (USDC on Solana):
  ┌──────────────────────────────────────┐
  │ 지갑 A → 블록체인 → 지갑 B            │
  │ 소요 시간: ~1초                        │
  │ 수수료: <$0.01                        │
  │ 운영 시간: 24/7/365                   │
  │ 추적: 완전 투명 (블록 익스플로러)       │
  └──────────────────────────────────────┘

비용 비교 ($10,000 송금):
  SWIFT: ~$40 + 환전 마진 ~$50 = ~$90
  USDC:  ~$0.01
  절감률: 99.99%
```

### 3.2 결제 인프라 비교

```
전통 카드 결제 (Visa/Mastercard):
  고객 → 가맹점 → 매입사(Acquirer) → 카드 네트워크 → 발행사(Issuer)
  수수료: 2~3% (가맹점 부담)
  정산: T+1~T+2 (1~2 영업일 후)
  분쟁: 차지백(Chargeback) 리스크

스테이블코인 결제:
  고객 → 블록체인 → 가맹점
  수수료: <0.1%
  정산: 즉시 (Final Settlement)
  분쟁: 없음 (비가역적 거래)

가맹점 입장의 비교:
  매출 $100만 기준:
    카드 결제 수수료: $20,000~30,000/년
    스테이블코인 수수료: <$1,000/년
    절감: $19,000~29,000/년
```

### 3.3 금융 접근성 비교

```
전통 금융:
  은행 계좌 개설 필요
    ↓
  신분증, 주소증명, 신용기록 필요
    ↓
  전 세계 은행 미보유 인구: ~14억 명 (World Bank)
    ↓
  달러 계좌는 더 어려움 (미국 거주 or 대형 은행 필요)

스테이블코인:
  스마트폰 + 인터넷만 있으면 됨
    ↓
  누구나 디지털 달러 보유 가능
    ↓
  은행이 없는 사람도 글로벌 경제에 참여 가능
    ↓
  특히 고인플레이션 국가에서 수요 폭발
     (아르헨티나, 터키, 나이지리아 등)
```

### 3.4 실사용 분포 (2025년 기준)

```
스테이블코인 사용 목적 분포:

DeFi 및 트레이딩    ████████████████████████████████  67%
해외 송금(Remittance) ████████                         15%
인플레이션 헤지      █████                             10%
상인 결제(Merchant)  ███                                5%
기타                 ██                                 3%
```

> 💡 **핵심 통찰**: 현재는 트레이딩이 주 사용처이지만, 해외 송금과 결제가 가장 빠르게 성장하는 영역이다. 특히 라틴아메리카에서 스테이블코인 활동의 71%가 국경 간 결제에 사용된다. 이것이 "실물 경제 침투"의 시작이다.

## 6. 달러 패권의 디지털 확장

### 6.1 전통적 달러 패권의 메커니즘

```
1944년 브레턴우즈 체제 이후 달러 패권의 기둥:

1기둥: 석유 달러 (Petrodollar)
  └── OPEC 석유 거래를 달러로만 결제
  └── 전 세계가 석유를 사려면 달러가 필요
  └── 달러 수요 = 달러 가치 유지

2기둥: SWIFT 시스템
  └── 국제 은행 간 송금의 표준 프로토콜
  └── 미국이 실질적으로 통제
  └── 제재 수단으로 활용 (이란, 러시아 SWIFT 차단)

3기둥: 미국 국채 시장
  └── 세계 최대, 최안전 채권 시장
  └── 전 세계 중앙은행이 외환보유고로 달러 자산 보유

→ 이 세 기둥이 달러를 기축통화로 만들었다
```

### 6.2 디지털 달러 패권 — 4번째 기둥

```
기존 3기둥의 한계:
  - 석유 달러: 탈탄소 + OPEC 다변화로 약화 중
  - SWIFT: 느림(2~5일), 비쌈($25~50), 대안 등장(CIPS, INSTEX)
  - 국채: 미국 재정적자 확대로 신뢰도 도전

4번째 기둥: 디지털 달러 (스테이블코인)
  ✅ 인터넷만 있으면 전 세계 누구나 달러 보유
  ✅ 은행 계좌 없이도 달러 경제에 참여
  ✅ 24/7 즉시 송금, 거의 무료
  ✅ 프로그래머블 — 스마트컨트랙트와 결합 가능
  ✅ 준비금으로 미국 국채 매입 → 1기둥 + 3기둥 강화

결과:
  인터넷 사용자 50억 명 → 잠재적 달러 사용자 50억 명
  기존: 달러 사용하려면 미국 은행 계좌 필요
  이후: 스마트폰만 있으면 달러 사용 가능
```

### 6.3 왜 달러 스테이블코인이 98%인가

```
전 세계 스테이블코인의 통화 분포:

달러(USD)  ████████████████████████████████████████████████  98%
유로(EUR)  █                                                 1%
기타       █                                                 1%

이유:
1. 선점 효과: USDT(2014), USDC(2018) 모두 달러 연동으로 시작
2. 네트워크 효과: 달러 스테이블코인 유동성이 압도적
3. 수요 측면: 고인플레이션 국가에서 "디지털 달러"에 대한 수요
4. 공급 측면: 미국 정부의 적극적 지원 (지니어스법)
5. 기축통화: 국제 거래의 기본 단위로서 달러의 위치

→ 중국(디지털 위안), EU(디지털 유로)가 추격하지만
→ 스테이블코인 시장에서 달러의 독주는 당분간 지속
```

### 6.4 지정학적 의미

```
미국의 전략적 계산:

스테이블코인 발행 증가
    ↓
준비금으로 미국 국채 $1,550억+ 보유 (2025.10 기준)
    ↓
미국 국채 수요 증가 → 차입 비용 감소
    ↓
동시에 전 세계에 "디지털 달러" 보급
    ↓
달러 패권 강화 + 재정 부담 경감

→ 미국 정부 입장에서 스테이블코인은 "공짜 국채 수요"를 만드는 기계
→ 규제를 통해 이 기계를 더 크고 안전하게 만드는 것이 지니어스법
```

> 💡 **핵심 통찰**: 스테이블코인은 기술이 아니라 **지정학적 무기**다. 미국이 이 기술을 "규제"하는 것은 억제가 아니라 **제도화를 통한 확산**이다. 이 맥락을 이해해야 시장의 방향을 읽을 수 있다.

## 7. 개발자에게 의미하는 것

### 7.1 수요-공급 불균형

```
수요 측 (스테이블코인 기술이 필요한 곳):
  ├── 기존 거래소: 규제 대응 시스템 업그레이드 필요
  ├── 은행: 스테이블코인 수탁/거래 서비스 구축
  ├── 핀테크: 스테이블코인 결제 통합
  ├── 기업: 국경 간 결제 인프라 전환
  └── 정부: CBDC 개발 (중앙은행 디지털 통화)
```
