# 1주차: 록펠러부터 스테이블코인까지 — 부의 원리

## 왜 이것부터 시작하는가?

코드를 한 줄 작성하기 전에, **왜 스테이블코인 거래소를 만들어야 하는지** 이해해야 한다. 기술은 도구일 뿐이고, 그 기술을 **어디에 쓸 것인가**가 결정적으로 중요하다.

역사적으로 엄청난 부를 축적한 사람들은 "남들이 아직 가치를 모르는 희소한 것을 먼저 확보"한 사람들이다. 이 패턴은 1870년대 록펠러의 석유부터 2025년 스테이블코인까지 동일하게 반복된다.

이번 주차에서는 부의 원리를 역사적으로 이해하고, 지금 스테이블코인 거래소 기술이 왜 "곡괭이 비즈니스"인지 파악한다.

## 1. 록펠러는 왜 그렇게 부자가 됐나

### 1.1 스탠더드 오일의 수직 통합

존 D. 록펠러(John D. Rockefeller)는 1870년 오하이오주에서 **스탠더드 오일(Standard Oil)**을 설립했다. 그가 한 일은 단순히 석유를 팔 것이 아니었다. 석유 산업의 **전 과정을 장악**했다.

```
석유 산업 밸류체인과 록펠러의 지배

  채굴(Extraction)
      ↓
  정유(Refining) ← 록펠러의 출발점
      ↓
  운송(Transportation) ← 파이프라인 + 철도 장악
      ↓
  유통(Distribution) ← 자체 유통망 구축
      ↓
  소매(Retail) ← 최종 소비자까지
```

이것을 **수직 통합(Vertical Integration)**이라 한다. 한 산업의 원재료 확보부터 최종 소비자 판매까지 모든 단계를 하나의 기업이 소유하는 전략이다.

1880년대에 스탠더드 오일은 미국 석유 정제 시장의 약 **90%**를 장악했다. 한 개인의 회사가 국가의 핵심 에너지 산업 거의 전부를 소유한 것이다.

### 1.2 철도 리베이트 — 경쟁사를 구조적으로 제거하기

록펠러는 단순히 좋은 제품을 만들어서 이긴 것이 아니다. **게임의 규칙 자체를 바꿨다.**

```
일반 정유사의 운송 구조:
  정유사 A → 철도 회사에 운송비 $1.00/배럴 지불

록펠러의 운송 구조:
  스탠더드 오일 → 철도 회사에 운송비 $0.35/배럴 지불 (리베이트 적용)
                + 경쟁사가 낸 $1.00 중 $0.25를 록펠러에게 환급 (드로백)

결과:
  정유사 A의 실제 운송 비용: $1.00/배럴
  록펠러의 실제 운송 비용:  $0.10/배럴 ($0.35 - $0.25)
```

이것이 **리베이트(Rebate)**와 **드로백(Drawback)** 구조다. 록펠러는 대량 운송을 보장하는 대가로 철도 회사에서 할인을 받았을 뿐 아니라, 경쟁사가 낸 운송비의 일부까지 되돌려 받았다.

경쟁사 입장에서는 사업을 하면 할수록 록펠러가 유리해지는 구조였다. 이 상태에서 경쟁사가 할 수 있는 것은 **록펠러에게 합병되는 것뿐**이었다.

> 💡 **핵심 통찰**: 록펠러는 경쟁에서 이긴 것이 아니라, 경쟁 자체가 불가능한 구조를 만들었다. 이것은 기술 산업에서 네트워크 효과, 플랫폼 락인과 동일한 원리다.

### 1.3 트러스트 구조 — 법의 빈틈 활용

1882년, 록펠러는 **스탠더드 오일 트러스트(Standard Oil Trust)**를 만들었다.

당시 미국법은 한 주(州)에서 설립된 회사가 다른 주의 회사를 직접 소유하는 것을 금지했다. 록펠러는 이 법을 **우회**했다.

```
트러스트 구조:

  주주들 (록펠러 포함)
      ↓ 주식을 신탁
  트러스트 위원회 (9명, 록펠러가 장악)
      ↓ 지배
  ┌──────────────────────────────────┐
  │ 오하이오 스탠더드 오일            │
  │ 뉴저지 스탠더드 오일              │
  │ 뉴욕 스탠더드 오일                │
  │ 캘리포니아 스탠더드 오일           │
  │ 인디애나 스탠더드 오일             │
  │ ... (약 40개 회사)                │
  └──────────────────────────────────┘
```

형식상 별개의 회사들이지만, 실질적으로는 록펠러가 트러스트 위원회를 통해 전부 지배하는 구조였다. 현대의 **지주회사(Holding Company)** 구조의 원형이다.

### 1.4 재투자와 복리 효과

록펠러는 수익을 사치에 쓰지 않았다. 지속적으로 **사업에 재투자**했고, 이후 금융, 철도, 철강 등 다양한 산업에 투자하며 자산을 **복리**로 불렸다.

```
복리의 위력 (연 15% 수익률 가정):

  시작: $1,000,000
  10년 후: $4,045,558
  20년 후: $16,366,537
  30년 후: $66,211,772
  40년 후: $267,863,546

  → 원금의 267배
```

### 1.5 분할 판결 — 쪼개졌는데 더 부자가 됐다

1911년, 미국 대법원은 스탠더드 오일을 **셔먼 반독점법(Sherman Antitrust Act)** 위반으로 판결하고, **34개 회사로 강제 분할**했다.

그런데 놀라운 일이 벌어졌다. 분할된 회사들의 주식 가치가 합산하면 분할 전보다 **더 높아졌다.**

```
분할 전: 스탠더드 오일 주가 = 시장이 매긴 가격 (독점 규제 리스크 반영)

분할 후: 34개 회사 각각이 독립 성장
  → 규제 리스크 해소
  → 각 회사의 잠재력이 개별적으로 평가됨
  → 주가 합산 > 분할 전 주가

록펠러는 34개 회사 모두의 주식을 보유
  → 분할 후 오히려 재산 증가
```

> 💡 **핵심 통찰**: 때로는 독점보다 분산이 더 큰 가치를 만든다. 현대 스핀오프(spin-off) 전략의 원형이다.

## 2. 스탠더드 오일의 후신들 — 현재까지 이어지는 석유 메이저

스탠더드 오일에서 분할된 회사들은 오늘날 세계 최대 기업들의 뿌리가 됐다.

### 2.1 주요 후신 회사

```
분할 당시 회사명                    현재 회사
─────────────────────────────────────────────
Standard Oil of New Jersey    →   ExxonMobil (엑슨)
Standard Oil of New York      →   ExxonMobil (모빌)
Standard Oil of Indiana       →   BP (아모코 거쳐)
Standard Oil of California    →   Chevron (셰브런)
Continental Oil               →   ConocoPhillips
Atlantic Richfield             →   BP
Ohio Oil                       →   Marathon Oil
Vacuum Oil Co.                →   Socony와 합병 → Mobil
Standard Oil of Ohio (Sohio)  →   BP에 인수
Standard Oil of Kentucky      →   셰브런에 인수 (1961)
```

### 2.2 사우디 아람코와의 연결

분할 후 스탠더드 오일 캘리포니아(현 셰브런)는 사우디아라비아와 합작 투자 계약을 체결했다. 사우디아라비아가 1980년 이 지분을 완전히 인수하면서 **사우디 아람코(Saudi Aramco)**가 탄생했다.

아람코는 현재 세계에서 가장 수익성 높은 기업 중 하나다.

```
록펠러의 스탠더드 오일
    ↓ 1911년 분할
Standard Oil of California
    ↓ 사우디 합작
CASOC (California-Arabian Standard Oil Company)
    ↓ 사우디 지분 인수 (1980)
Saudi Aramco (사우디 아람코)
    ↓ 2019년 IPO
세계 최대 기업 가치 ($2T+)
```

### 2.3 석유 밖으로 이어진 후신들

록펠러의 유산은 석유 산업을 넘어 의외의 곳까지 뻗어 있다.

- **바셀린(Vaseline)** — 스탠더드 오일의 석유 부산물 회사 Chesebrough에서 시작, 현재 유니레버 소유
- **트랜스유니온(TransUnion)** — Union Tank Car Company에서 분리된 신용정보 회사, 현재 3대 신용평가사 중 하나

> 💡 **핵심 통찰**: 한 산업의 독점은 예상치 못한 산업으로 확장된다. 현대의 빅테크도 동일한 패턴을 보인다 (구글: 검색 → 광고 → 클라우드 → AI).

## 3. 부의 핵심 원리 — 선점 + 희소성

록펠러의 부는 독과점이 가능했던 시대에 핵심 자원을 선점한 결과다. 이 원리는 **어느 시대에서든** 동일하게 작동한다.

### 3.1 시대별 선점의 대상

```
시대        자산              선점 시기        희소성 원리
─────────────────────────────────────────────────────────
19세기     석유 (록펠러)     1870년대         매장량 한계
20세기     부동산            도시 개발 초기    땅은 새로 만들 수 없음
2010년대   비트코인          2009~2013년      발행량 2,100만개 고정
2000년대   플랫폼/데이터     2000년대 초      네트워크 효과
2020년대   스테이블코인 인프라 지금(!)         규제 프레임워크 형성기
```

### 3.2 패턴 분석

모든 경우에 공통되는 패턴이 있다:

```
1단계: 새로운 자산/기술이 등장한다
    ↓
2단계: 대부분의 사람들이 가치를 인식하지 못한다
    ↓
3단계: 소수가 먼저 진입하여 확보한다
    ↓
4단계: 대중이 가치를 인식하기 시작한다
    ↓
5단계: 진입 비용이 급격히 상승한다
    ↓
6단계: 먼저 확보한 소수가 엄청난 가치를 보유하게 된다
```

**핵심 질문**: 지금 이 사이클의 2~3단계에 있는 것은 무엇인가?

### 3.3 스테이블코인 인프라 — 지금이 선점의 시기

```
스테이블코인 인프라의 현재 위치:

  ✅ 1단계: 기술 등장 (2014, Tether 출시)
  ✅ 2단계: 대중 무관심 (2014-2020)
  ✅ 3단계: 소수 진입 (2020-2024, Circle, 바이낸스)
  🔶 4단계: 가치 인식 시작 (2025, 지니어스법 서명) ← 현재 위치
  ⬜ 5단계: 진입 비용 급상승 (아직 오지 않음)
  ⬜ 6단계: 시장 포화

→ 기술력을 확보하기에 아직 늦지 않은, 마지막 기회의 창
```

## 4. 스테이블코인과 달러 패권

### 4.1 미국의 스테이블코인 전략

2025년 7월 18일, 트럼프 대통령이 **지니어스법(GENIUS Act: Guiding and Establishing National Innovation for U.S. Stablecoins Act)**에 서명했다.

미국이 스테이블코인을 단순한 기술이 아닌 **경제·금융·안보 전략의 핵심 수단**으로 인식하고 있다는 것을 보여주는 법안이다.

```
지니어스법의 핵심 조항:

1. 준비금 요건
   └── 발행사는 1:1 준비금을 미국 국채 또는 현금으로 보유해야 함
       → 미국 국채 수요 증가 → 미국 재정에 도움

2. 발행사 규제
   └── 연방 또는 주 차원 라이선스 필수
       → 불량 스테이블코인 퇴출

3. 외국 발행사 제한
   └── 미국 시장 진입 시 미국 규제 체계에 복종
       → 달러 기반 글로벌 규제 프레임 확립

4. 소비자 보호
   └── 파산 시 준비금은 소비자에게 우선 반환
       → 신뢰성 확보
```

### 4.2 왜 달러 패권인가

전 세계 스테이블코인의 **98~99%가 달러에 연동**되어 있다.

```
전통 금융                        스테이블코인
────────────────────────────────────────────────
은행 계좌                   →    디지털 월렛
SWIFT 국제송금 (2-5일)      →    블록체인 즉시 송금 (수 분)
달러 현물 유통              →    달러 연동 코인 유통
미국 금융 패권              →    디지털 달러 패권
미국 은행 계좌 필요         →    인터넷만 있으면 달러 보유 가능
```

미국 입장에서 스테이블코인은 **달러의 영향력을 전 세계 인터넷 사용자에게 확장하는 도구**다.

### 4.3 시장 규모

```
스테이블코인 시가총액 추이:

2020년: ~$120억 (약 16조 원)
2021년: ~$600억 (약 81조 원)
2022년: ~$1,500억 (약 203조 원)
2023년: ~$1,200억 (약 163조 원) — 시장 조정
2024년: ~$2,000억 (약 272조 원)
2025년 7월: ~$2,585억 (약 352조 원)

→ 5년 만에 22배 이상 성장
→ 주요 금융 기관들의 진입이 이제 시작
```

## 5. 거래소 기술 — 곡괭이 비즈니스

### 5.1 금광 시대의 교훈

1849년 캘리포니아 골드러시 때, 가장 안정적으로 부를 축적한 사람들은 금을 캔 사람들이 아니었다.

```
금을 캔 사람들:
  - 대부분 실패 (금 발견 확률 낮음)
  - 성공하더라도 경쟁 치열
  - 물리적 위험 높음

곡괭이를 판 사람들:
  - 안정적 수요 (모든 광부에게 필요)
  - 위험 낮음 (금 발견 여부와 무관)
  - 확장 가능 (수요 증가 시 생산 확대)

예시: 리바이 스트라우스 — 광부용 작업복을 팔아서 Levi's 설립
```

### 5.2 스테이블코인 시대의 곡괭이

거래소 **자체를 운영**하는 것은 거대한 자본, 라이선스, 법적 리스크가 필요하다. 하지만 거래소를 **만드는 기술력**은 그 자체로 강력한 자산이 된다.

```
기술력 기반 비즈니스 모델:

┌─────────────────┬──────────────────────────┬─────────────────────┐
│ 모델             │ 설명                      │ 비유                 │
├─────────────────┼──────────────────────────┼─────────────────────┤
│ 거래소 SaaS      │ 거래소 플랫폼을 기업에 판매 │ AWS처럼 인프라 제공   │
│ White-label      │ 은행/핀테크에 엔진 공급     │ 은행이 자체 브랜드 운영│
│ 결제 인프라      │ 스테이블코인 결제 모듈 판매  │ 쇼핑몰, 커머스에 탑재 │
│ 컴플라이언스     │ AML/KYC 솔루션 판매        │ 규제 대응 기술 판매   │
└─────────────────┴──────────────────────────┴─────────────────────┘
```

### 5.3 지금이 기회인 세 가지 이유

```
1. 규제 프레임워크가 막 만들어지는 시점
   └── 지니어스법이 2025년에 서명됨
       → 규제 요구사항을 기술로 구현할 수 있는 사람이 필요

2. 기술 표준이 아직 정해지지 않은 시점
   └── 매칭 엔진, 지갑 관리, KYC 플로우 등의 "표준 솔루션"이 아직 없음
       → 표준을 만드는 사람이 시장을 지배

3. 선점 효과가 극대화되는 시점
   └── 대형 금융 기관들이 이제 막 진입 시작
       → 기술 인력 수요 > 공급
       → 기술을 가진 사람의 협상력 극대화
```

## 6. 개발자 로드맵 개요

### 6.1 왜 러스트인가

```
거래소 핵심 기술 요구사항:

매칭 엔진 성능: 초당 수만~수십만 건 주문 처리
  → C/C++ 수준 성능이 필요
  → 하지만 메모리 안전성도 필수 (금융 시스템)
  → 러스트 = 성능 + 안전성

업계 동향:
  - Solana 블록체인: 러스트로 작성
  - 바이낸스: 핵심 엔진을 러스트로 전환 중
  - 주요 DeFi 프로토콜: 러스트 기반 증가
  - Linux 커널: 러스트 지원 시작 (안정성 인정)

결론: 거래소 백엔드에서 러스트는 업계 표준으로 수렴 중
```

### 6.2 기존 스킬 활용 전략

이미 보유한 기술을 최대한 활용하고, **러스트만 새로 배우면** 거래소의 모든 레이어를 커버할 수 있다.

```
보유 스킬              거래소에서 역할           학습 필요도
──────────────────────────────────────────────────────────
React/Next.js    →    거래소 프론트엔드         ✅ 바로 활용
Node.js          →    ethers.js 블록체인 연동   ✅ 바로 활용
Java/Spring      →    거래 API 서버            ✅ 바로 활용
러스트            →    매칭 엔진 (핵심)          🔶 학습 필요
블록체인/Web3     →    스테이블코인 연동         🔶 학습 필요
```

### 6.3 커리어 경로

```
현재: 풀스택 개발자 (React + Spring + Node.js)
  ↓  러스트 + 블록체인 학습
1년 후: 블록체인 풀스택 개발자
  ↓  거래소 경험 축적
2-3년 후: 거래소 백엔드 엔지니어 (러스트 전문)
  ↓  기술력 + 도메인 지식 + 인적 네트워크
3-5년 후: 거래소 기술 창업 or 핵심 인재
```
