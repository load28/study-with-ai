# Claude Code 에이전트 구조 학습 로드맵

## 학습 목표
Claude Code에서 일을 나눠 맡기는 세 가지 단위 — **메인 에이전트(메인 대화)**, **서브에이전트**, **에이전트 팀** — 의 차이를 이해하고, 작업 성격에 맞게 골라 쓰며 직접 서브에이전트를 설계할 수 있게 된다.

## 학습 철학
- **컨텍스트가 핵심 축**: "누가 무엇을 보고, 무엇을 돌려주는가"로 모든 차이를 설명한다
- **공식 문서 기반**: 모든 사실은 Claude Code 공식 문서에서 가져오고 출처를 남긴다
- **점진적 심화**: 개념 비교 → 서브에이전트 설계 → 에이전트 팀 협업 순서
- **실전 중심**: 각 주차마다 직접 만들어 보는 실습을 둔다

## 학습 방법
- 각 주차는 독립적인 문서로 제공된다 (`week-XXX.md`, 3자리)
- **왜 배우는가 → 핵심 개념 → 예제 → 실습 → 체크리스트** 순서

## 전체 학습 계획

### Phase 1: 기본 구조 이해

**[1주차: 메인 에이전트 vs 서브에이전트 vs 에이전트 팀](week-001.md)**
- 메인 대화와 서브에이전트의 컨텍스트 격리
- 서브에이전트가 상속하는 것과 상속하지 않는 것 (도구·권한·모델·프롬프트)
- 서브에이전트와 에이전트 팀의 비교표
- 선택 기준: 언제 무엇을 쓰는가

### Phase 2: 서브에이전트 설계 (예정)

**2주차: 서브에이전트 정의 파일 직접 만들기**
- frontmatter(name, description, tools, model) 설계
- 정의 위치와 우선순위
- 도구 허용·차단 목록으로 권한 줄이기

### Phase 3: 에이전트 팀 (예정)

**3주차: 에이전트 팀으로 협업시키기**
- Team lead, Teammates, 공유 Task list, Mailbox
- 팀 크기와 제약
- 서브에이전트 정의를 팀원 역할로 재사용하기
